# flashcards

**Умное десктопное приложение для интервального повторения и заучивания материала с помощью интерактивных карточек и встроенного математического модуля.** 

Проект разработан в рамках учебного курса от Яндекса.

---

##  Описание проекта

Приложение представляет собой удобный тренажер для запоминания информации (аналог Anki), адаптированный под разные учебные сценарии. В отличие от классических текстовых карточек, данный проект поддерживает мультимедийный контент и содержит специальный математический режим для визуализации графиков в реальном времени.

### Ключевые возможности:

*  **Мультимедийные карточки:** Пользователь может создавать двусторонние карточки, добавляя на них не только текст (термины, определения, правила), но и изображения для визуального запоминания.
*  **Удобная структуризация:** Возможность объединять карточки в тематические группы (колоды) для удобной организации учебного процесса (например, «Английский язык», «История», «Программирование»).
*  **Гибкие режимы обучения:** 
  * *Фокус на одном:* Тренировка карточек строго из одной выбранной группы.
  * *Тематический микс:* Одновременное повторение карточек из нескольких конкретных групп на выбор.
  * *Глобальный марафон:* Режим случайного перебора абсолютно всех карточек, существующих в базе.
*  **Интерактивный математический модуль:** Специальный режим, где пользователь может ввести математическую функцию (например, $y = x^2$ или $y = \sin(x)$). Приложение автоматически обработает ввод и построит интерактивный график на экране для проверки знаний и визуализации закономерностей.
