# Flashcards

## Идея проекта
**Flashcards** — это умное десктопное приложение для интервального повторения и заучивания материала. Оно решает проблему эффективного запоминания больших объемов информации (от иностранных слов до сложных формул).

## Цель и задачи

### Цель проекта
Создать локальное десктопное приложение-тренажер с поддержкой изображений, гибкой фильтрацией колод.

### Основные функции
* **Управление колодами:** Создание, редактирование и удаление тематических групп карточек.
* **Мультимедийные карточки:** Поддержка двусторонних карточек с текстом и изображениями.
* **Гибкие режимы обучения:** Повторение одной колоды, микс из выбранных групп или глобальный марафон по всей базе.
* **Импорт и экспорт:** Массовая загрузка и сохранение данных в форматах CSV и Excel (`.xlsx`).
